AP-CSA-Projects

This is an archive of the projects completed during AP Computer Science A, with each folder corresponding to a unit of the curriculum. The repo is entirely Java and covers foundational data structures, recursion, string processing, and small applied programs built around class objects.

Contents

CSA-Palindrome-Anagram covers string manipulation logic, checking whether a given string reads the same forwards and backwards and whether two strings are letter-for-letter rearrangements of each other. CSA-Recursion-String-Decoder works through recursive string processing, likely decoding a compressed or encoded string format by breaking the problem down into smaller recursive calls. CSA-Scribble-Board implements a 2D grid or board structure, the kind of project AP CSA uses to practice array-of-arrays manipulation and object placement logic. CSA-Songs-And-Playlists models a collection of song objects organized into playlists, practicing class design, object composition, and list manipulation. CSA-StudentID builds a class representing a student record, likely focused on constructors, instance variables, and encapsulation basics.
